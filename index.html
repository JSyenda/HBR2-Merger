Une dos grabaciones de Haxball (.hbr2) en una sola.
Todo se procesa íntegramente en tu navegador: los archivos no se suben a ningún servidor y las recs quedan guardadas localmente (se restauran con el enlace ?job=…).
Estás abriendo este archivo con doble clic (protocolo file://). Chrome bloquea los Web Workers en file://, así que la fusión no puede arrancar. Ábrelo a través de un servidor local (por ejemplo npx serve, la extensión "Live Server" de VS Code o python -m http.server dentro de esta carpeta) o súbelo a GitHub Pages, que es para lo que está preparado.
Arrastra aquí hasta 2 archivos .hbr2 o haz clic para elegirlos.
El primero será la Rec 1 (inicio), el segundo la Rec 2 (continuación). Puedes intercambiarlos después. Si ya hay 2 recs, una nueva las sustituye en orden rotativo (Rec 1, luego Rec 2).
PosiciónArchivoTamaño
Rec 1 · inicio (ninguna)
Rec 2 · continuación (ninguna)
Si la fusión falla o la rec resultante no se reproduce, prueba a intercambiar el orden de las grabaciones.
Modo de fusión
En caso de que no funcione el Modo Estándar, prueba con el Modo Exacto. Ten en cuenta que puede llegar a fallar.
